Part 1: Multiple-Choice Questions (Questions 1–70)
Section A: Classical ML, Feature Engineering & Fraud/Anomaly Detection (Q1–Q14)
1. In a dataset where positive fraud cases represent only 0.05% of traffic, why is ROC-AUC often misleading compared to Precision-Recall AUC (PR-AUC)?
 * A) ROC-AUC cannot be computed when class weights are applied.
 * B) The massive number of True Negatives keeps the False Positive Rate artificially low, making mediocre models appear to have an ROC-AUC > 0.98.
 * C) PR-AUC automatically resamples the minority class during evaluation.
 * D) ROC-AUC only evaluates the 0.50 probability threshold.
 * Answer: B | Why: False Positive Rate is FP / (FP + TN). When TN is in the millions, thousands of false alarms barely move the FPR needle, whereas Precision (TP / (TP + FP)) exposes false positives immediately.
2. You are computing a user's "30-day rolling chargeback rate" for a training dataset. Which practice introduces fatal data leakage?
 * A) Computing the rolling window using only timestamps strictly prior to the target transaction's timestamp.
 * B) Applying a missing-value indicator column when a user has zero prior history.
 * C) Calculating the mean and standard deviation scaling parameters across the entire dataset before performing the chronological train/validation split.
 * D) Using log-transformation on skewed transaction amounts fit only on the training split.
 * Answer: C | Why: Fitting scalers, imputers, or target encoders on the combined dataset leaks future distribution statistics and validation variance into the training set.
3. Why does a bare decision tree or Logistic Regression outputs often require post-hoc probability calibration (Platt Scaling or Isotonic Regression) in risk scoring engines?
 * A) Calibration increases the model's top-1 classification accuracy.
 * B) Downstream expected-value rules (e.g., Risk Score × Transaction Dollar Amount > Threshold) require predicted scores to match true empirical frequencies.
 * C) Calibration reduces inference latency by pruning tree nodes.
 * D) Isotonic regression converts sparse features into dense embeddings.
 * Answer: B | Why: Boosted trees and maximum-margin classifiers push probabilities toward 0 and 1 or distort them; expected-loss math requires a score of 0.15 to mean an actual 15% empirical default/fraud rate.
4. When should you prefer Platt Scaling (sigmoid calibration) over Isotonic Regression?
 * A) When the calibration dataset is small (e.g., fewer than 1,000 samples) and you want to avoid overfitting the calibration curve.
 * B) When the uncalibrated distortion is non-monotonic and you have millions of calibration examples.
 * C) When training multiclass image classifiers exclusively.
 * D) When you want a non-parametric step-function transformation.
 * Answer: A | Why: Isotonic regression is non-parametric and has high variance on small calibration sets; Platt Scaling fits only two parameters (A and B in a logistic sigmoid) and resists overfitting.
5. What is the primary mechanism of L1 (Lasso) regularization compared to L2 (Ridge) regularization?
 * A) L1 penalizes the squared magnitude of weights, shrinking correlated features evenly.
 * B) L1 penalizes the absolute value of weights (\lambda \sum |w_i|), producing sparse models by driving uninformative feature weights to exactly zero.
 * C) L1 guarantees a closed-form analytical matrix solution.
 * D) L1 prevents exploding gradients in recurrent neural networks.
 * Answer: B | Why: The constant subgradient of the L1 norm at small values forces weak weights all the way to zero, acting as built-in feature selection.
6. How does an Isolation Forest detect anomalies in unlabeled tabular telemetry?
 * A) By calculating the Mahalanobis distance from a Gaussian centroid.
 * B) By randomly selecting features and split values, isolating true anomalies in significantly fewer splits (shorter average path length from the root) than normal points.
 * C) By training an autoencoder and measuring pixel reconstruction loss.
 * D) By building a minimum spanning tree over k-nearest neighbors.
 * Answer: B | Why: Anomalies are few and different, so random hyperplanes isolate them near the root of random trees much faster than dense clusters.
7. When encoding a high-cardinality categorical feature (e.g., merchant_id with 200,000 unique values) using Target Encoding, how do you prevent severe overfitting?
 * A) Replace all rare merchants with the global maximum target value.
 * B) Use Out-of-Fold (OOF) target statistics combined with empirical Bayes smoothing (blending the category mean with the global prior based on sample count n).
 * C) Apply standard One-Hot Encoding across all 200,000 columns.
 * D) Sort merchant IDs alphabetically and assign ordinal integers 1..200,000.
 * Answer: B | Why: Without smoothing and out-of-fold calculation, a merchant with 1 transaction that happened to be fraudulent gets a target encoding of 1.0, memorizing the label directly.
8. In TF-IDF vectorization for text classification, why are sublinear term frequency scaling (1 + \log(\text{tf})) and character n-grams (n=3..5) effective against adversarial spam/smishing?
 * A) They translate foreign characters into ASCII automatically.

 * D) They replace the need for a downstream classifier.
 * Answer: B | Why: Attackers intentionally insert typos, homoglyphs, and punctuation to evade word-level vocabularies; overlapping character n-grams retain high cosine similarity despite character substitutions.

 * Answer: B | Why: Any discrepancy between how historical aggregations are reconstructed offline and how streaming counters accumulate online changes the feature distribution at inference time.
10. If your fraud model's False Positive cost (blocking a legitimate user's 2FA code) is 50x higher than its False Negative cost (letting a spam message through), how should you adjust the decision boundary?
 * A) Lower the classification probability threshold from 0.50 to 0.05.
 * B) Raise the classification probability threshold toward 0.95+ (or introduce an intermediate FLAG review band) to maximize Precision at the high-confidence tail.
 * C) Retrain the model with L1 loss instead of cross-entropy.
 * D) Randomly drop 50% of positive examples from the training set.
 * Answer: B | Why: Bayes optimal decision theory places the threshold at p^* = \frac{C_{FP}}{C_{FP} + C_{FN}}. When C_{FP} = 50 and C_{FN} = 1, p^* = \frac{50}{51} \approx 0.98.

Section B: Ultra-Low-Latency Inference, ONNX & Real-Time Data Stores (Q15–Q28)

 * D) ONNX caches every possible input string in a lookup table.
 * Answer: B | Why: For single-item online requests (batch_size=1), Python wrapper overhead and intermediate NumPy array allocations dominate execution time; C++ graph execution eliminates that overhead.

 * Answer: B | Why: Thread synchronization overhead exceeds the <0.1ms compute time of a small model; scaling horizontally via independent single-threaded worker processes yields much tighter p99 tail latency.

Section C: MLOps, Drift Detection, CI/CD & Observability (Q29–Q42)
29. What is the fundamental difference between "Data Drift" (Covariate Shift) and "Concept Drift"?

 * C) Data drift requires ground-truth labels to detect; Concept drift does not.
 * D) They are identical terms.
 * Answer: A | Why: If holiday shopping raises average transaction amounts (P(X) shifts), that is Data Drift; if scammers invent a brand-new pretext where previously safe patterns are now fraudulent (P(Y|X) shifts), that is Concept Drift.
